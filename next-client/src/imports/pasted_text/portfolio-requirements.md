# Retro-Futuristic Developer Portfolio — Website Requirements

## 1. Website Style

Create a modern personal portfolio website using a **Retro-Futurism** visual style.

### Design Direction

* Retro-futuristic / cyberpunk-inspired aesthetic
* Dark background with neon accents
* Futuristic typography and UI elements
* CRT / terminal-inspired details where appropriate
* Grid-based layouts
* Glowing borders and subtle neon effects
* Smooth animations and transitions
* Responsive design for desktop, tablet, and mobile
* Use **Google Fonts** for the typography

The design should feel futuristic without becoming difficult to read or overly flashy.

---

# 2. Main Navigation

The website will contain four main pages:

1. **Home**
2. **Resume**
3. **Projects**
4. **Contact**

Navigation should be available throughout the website.

---

# 7. Visual Design System

### Color Direction

Use a dark retro-futuristic palette with neon accents.

Possible colors:

* Deep black / dark navy background
* Neon cyan
* Electric purple
* Neon green
* Bright white text

Avoid using too many colors simultaneously.

### Typography

Use Google Fonts.

A possible combination:

**Primary Font:** Space Grotesk
**Display / Futuristic Font:** Orbitron
**Monospace / Terminal Font:** JetBrains Mono

Use the display font for headings and the monospace font for technical/terminal elements.

---

# 8. UI Elements

Use subtle retro-futuristic elements throughout the website:

* Neon borders
* Glowing buttons
* Terminal windows
* Pixel/grid backgrounds
* Scanline effects
* HUD-style cards
* Digital labels
* Futuristic icons
* Animated gradients
* Hover glow effects
* Loading animations

Animations should remain subtle and should not negatively affect usability or performance.

---

# 9. Responsive Design

The website must work properly on:

* Desktop
* Laptop
* Tablet
* Mobile

The retro-futuristic aesthetic should remain consistent across all screen sizes.

---

# 10. Overall User Experience

The website should communicate:

**Developer + Technology + Creativity + Futuristic Personality**

The design should feel like a combination of:

> **Personal developer portfolio × futuristic computer interface × retro sci-fi**

while still maintaining professional readability and usability.
